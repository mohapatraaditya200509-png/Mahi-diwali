# A DIWALI SURPRISE FOR MAHI ❤️

A cinematic, fully-client-side Diwali love letter — a short film you experience in a
browser. Made with love by **Aditya**.

Open the link, tap **START EXPERIENCE**, and the night unfolds: a glowing diya under a
starry sky, fireworks and rose petals, her name written in golden particles, a beating
heart, and a final message that stays until she chooses to replay.

---

## The experience

| Scene | What happens |
|-------|--------------|
| 1 · Opening | Midnight sky, floating golden lights, a flickering diya. *"Some moments are made special… by someone special."* → **MAHI ❤️** |
| 2 · Diwali magic | Realistic fireworks, golden sparks, falling rose petals, a row of glowing diyas |
| 3 · Name reveal | The screen darkens; golden particles gather and form **MAHI** — *"You make ordinary moments extraordinary. ❤️"* |
| 4 · Heart | A gently beating glowing heart surrounded by orbiting golden particles — *"Distance doesn't matter when someone lives in your heart."* |
| 5 · Final message | Fireworks over a peaceful night sky, lines revealed one by one, ending with **With love, Aditya ❤️** — plus Replay |

Controls are deliberately minimal: **Start**, **Skip** (top-right), **Mute/Unmute**
(top-right), **Replay** (final screen).

## Tech

- Plain **HTML5 + CSS3 + vanilla JavaScript** — no frameworks, no build step, no backend
- **Canvas API** for stars, golden motes, fireworks, rose petals, the particle-name
  reveal and the heart's orbit
- **Web Audio / HTML5 `<audio>`** for the background piano (fully optional)
- Mobile-first, responsive (portrait & landscape), safe-area aware
- Honours `prefers-reduced-motion`, pauses rendering when the tab is hidden
- All assets local — zero external requests, works offline after first load

## Project structure

```
mahi-diwali/
├── index.html                  # markup for all five scenes
├── style.css                   # cinematic styling, animations, responsive rules
├── script.js                   # scene director · canvas FX engine · audio · controls
├── assets/
│   └── music/
│       ├── diwali-piano.mp3    # original 64-second piano loop (the background music)
│       └── generate_music.py   # the synthesizer that created it (provenance)
├── README.md
└── DEPLOYMENT.md               # step-by-step GitHub Pages publishing guide
```

There is no `assets/images/` folder on purpose: **every visual is generated procedurally**
(CSS, SVG and Canvas), so no image files are needed. Nothing is fetched from the internet.

## The music

`assets/music/diwali-piano.mp3` is an **original ambient piano piece synthesized from
scratch** (additive synthesis + a small reverb, generated by `generate_music.py`) — so
there are no copyright issues with sending this to anyone.

- Music is **never required**: the site is fully functional with sound off or if the
  file is ever removed (it silently falls back to a soft generated pad, no errors)
- Playback starts only after **START EXPERIENCE** (respects mobile autoplay rules)
- The **mute button** (top-right) toggles it at any time

To change the music, replace `assets/music/diwali-piano.mp3` with any mp3 of the same
name (keep it short and gentle), or regenerate with:

```bash
cd assets/music && python3 generate_music.py   # requires ffmpeg with libmp3lame
```

## Run locally

Any static server works; opening `index.html` directly also works:

```bash
cd mahi-diwali
python3 -m http.server 8000
# then open http://localhost:8000
```

## Customising the words

All text lives in `index.html` — search for `MAHI`, `Aditya`, or the final message
lines and edit them directly. Scene timing (how long each scene lasts) is controlled
in `script.js` under the `Director` section (`SW + …` millisecond values).

A small debug handle is exposed as `window.__mahi` (`Director`, `Sound`, `FX`) for
console tinkering — it has no effect on the experience.

## Browser support

Tested on desktop Chromium and headless Chrome at 390×844, 320×568 and 844×390
(portrait/landscape). Uses widely supported APIs (`canvas`, `AudioContext`, CSS
custom properties, `clamp()`), so it also runs on Android Chrome, iPhone Safari,
Firefox and Edge. Tested with and without `prefers-reduced-motion`.
